# Roadmap

The roadmap is ordered to establish secure process boundaries before adding behavior that depends on them.

## Version 0.1

| Sequence | Feature                                 | Status      | Plan                                            |
| -------- | --------------------------------------- | ----------- | ----------------------------------------------- |
| 1        | Application shell and security baseline | Implemented | [001](features/001-application-shell.md)        |
| 2        | Focus session engine                    | Implemented | [002](features/002-focus-session-engine.md)     |
| 3        | Foreground application awareness        | Implemented | [003](features/003-application-awareness.md)    |
| 4        | Floating pet overlay                    | In progress | [004](features/004-pet-overlay.md)              |
| 5        | Nudge and intervention ladder           | In progress | [005](features/005-nudge-escalation.md)         |
| 6        | Settings and local persistence          | In progress | [006](features/006-settings-and-persistence.md) |
| 7        | Custom pet packs                        | Planned     | [007](features/007-custom-pet-packs.md)         |
| 8        | Packaging and first release             | In progress | [008](features/008-packaging-and-release.md)    |
| 9        | Update availability notices             | Implemented | [009](features/009-update-notices.md)           |

## Deferred beyond version 0.1

- Browser-domain awareness
- VS Code workspace awareness
- Windows and Linux support
- Optional cloud synchronization
- Community pet gallery
- AI-generated conversation or coaching

Deferred items are ideas, not commitments. Each requires a new feature plan and privacy review before implementation.
